# 青禾智灌 —— 校园网服务器部署说明

> 目标：把这台电脑变成一台**校园网内其他人也能访问**的服务器。
> 同学在浏览器输入 `http://<你的校园网IP>:5000` 就能打开登录页、注册账号并使用。

---

## 一、环境要求

| 项目 | 要求 | 检查命令 |
| --- | --- | --- |
| 操作系统 | Windows 10 / 11（脚本为 .bat；Linux 可直接 `python server.py`） | — |
| Python | 3.10 或更高（开发验证环境 3.14.5） | `python --version` |
| 网络 | 与同学处于**同一个校园网 / 同一台路由器**下 | `ipconfig` |
| 端口 | 5000 未被占用（可用 `PORT` 改端口） | `netstat -ano \| findstr :5000` |

安装依赖（项目根目录执行）：

```bat
cd /d D:\AI\Farm
python -m pip install -r requirements.txt
```

> 依赖含 `waitress`（生产 WSGI 服务器）、`flask`、`flask-socketio`、`paho-mqtt`、`pyjwt`、`requests`、`pytest`。
> 若下载慢，可加国内源：`python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

## 二、开发模式 vs 生产模式（先选对启动方式）

本项目有两个入口，**给别人访问必须用生产模式**：

| | 开发模式 | 生产模式 |
| --- | --- | --- |
| 启动命令 | `python app.py`（或双击 `run.bat`） | `python server.py`（或双击 `start_server.bat`） |
| HTTP 服务器 | Werkzeug 内置（单线程为主） | **waitress**（多线程 WSGI，Windows 友好） |
| `FARM_DEBUG` | `1`（开启调试器） | `0`（关闭） |
| 监听地址 | `0.0.0.0` | `HOST` 环境变量，默认 `0.0.0.0` |
| 局域网地址提示 | 无 | **打印所有可用校园网地址** |
| 适用场景 | 自己改代码、看报错堆栈 | 校园网内给同学访问 |
| 安全风险 | 调试器可远程执行代码，**严禁对外开放** | 相对安全，但仍为 HTTP 明文 |

选择建议：

- 只是自己调代码 → `run.bat`
- 要让同学访问 → `start_server.bat`（本文档后续均按此展开）

> 两种模式下 SocketIO 都使用 `threading` 异步模式。这是**刻意选择**：本项目 MQTT 回调在
> 后台线程里调用 `socketio.emit(...)`，`threading` 模式与 paho-mqtt 后台线程兼容性最好；
> 改用 eventlet/gevent 会因 monkey-patch 与 paho-mqtt 线程冲突，属于本项目的高风险改动。

### 环境变量清单

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `FARM_SECRET_KEY` | 内置兜底值（**不安全**） | 会话 / JWT 签名密钥，**必须**设为随机长字符串 |
| `FARM_DB_PATH` | `qinghe.db` | SQLite 数据库文件路径 |
| `HOST` | `0.0.0.0` | 监听地址。`0.0.0.0` = 所有网卡（别人才能连）；`127.0.0.1` = 仅本机 |
| `PORT` | `5000` | 监听端口 |
| `FARM_DEBUG` | `0` | 调试开关。对外开放**必须**为 `0` |
| `FARM_THREADS` | `8` | waitress 工作线程数，访问量大时可调高 |

### 生成 `.env`

```bat
cd /d D:\AI\Farm
python tools/gen_secret.py
```

该脚本用 `secrets.token_urlsafe(48)` 生成随机密钥，并基于 `.env.example` 模板写出 `.env`。
**若 `.env` 已存在则不会覆盖**（避免换掉正在使用的密钥导致所有人掉线）；确需重新生成：

```bat
python tools/gen_secret.py --force
```

也可以手工配置：复制 `.env.example` 为 `.env`，填写 `FARM_SECRET_KEY` 等值。

> `.env` 已被 `.gitignore` 忽略，不会提交到仓库。**切勿**把它发给别人或上传到网上。

## 三、三步部署

### 第 1 步：安装依赖

```bat
cd /d D:\AI\Farm
python -m pip install -r requirements.txt
```

### 第 2 步：放行防火墙

**右键 `firewall_allow.bat` → 「以管理员身份运行」**（脚本会自动检测管理员权限，非管理员会直接退出并提示）。

```bat
netsh advfirewall firewall add rule name="青禾智灌 5000" dir=in action=allow protocol=TCP localport=5000
```

看到 `[完成] 已放行 TCP 5000 端口` 即成功。
删除规则：`netsh advfirewall firewall delete rule name="青禾智灌 5000"`

### 第 3 步：启动服务

**双击 `start_server.bat`**。脚本会自动：关闭调试（`FARM_DEBUG=0`）→ 生成密钥 `.env` → 检查依赖 → 启动 waitress。

启动成功时窗口会打印：

```
==========================================================
  青禾智灌服务已启动
==========================================================
  本机访问:   http://127.0.0.1:5000
  校园网访问: http://10.113.158.198:5000   ← 把这个地址发给同学
  监听地址:   0.0.0.0:5000
  调试模式:   关闭（生产模式）
  异步模式:   threading
==========================================================
  停止服务：本窗口按 Ctrl+C，或运行 stop_server.bat
==========================================================
```

> **本窗口不能关**：关掉窗口服务就停了。要停止请按 `Ctrl+C`，或双击 `stop_server.bat`
> （该脚本会先打印出占用端口的 PID 与进程名，**确认后**才结束进程，不会盲杀）。

**本地开发调试**用 `run.bat`（`FARM_DEBUG=1`，仅本机、**禁止对外开放**）。

### 确认监听在 `0.0.0.0:<port>`

启动后另开一个窗口执行：

```bat
netstat -ano | findstr :5000
```

正确输出（关键是**本地地址为 `0.0.0.0:5000`**，表示所有网卡都在监听）：

```
  TCP    0.0.0.0:5000           0.0.0.0:0              LISTENING       6296
```

若显示的是 `127.0.0.1:5000`，说明只绑定了本机，**同学连不上**——
请检查是否误设了 `HOST=127.0.0.1`，改回 `0.0.0.0` 后重启。

PowerShell 等价检查：

```powershell
Get-NetTCPConnection -LocalPort 5000 -State Listen | Select-Object LocalAddress,LocalPort,OwningProcess
```

## 四、同学如何访问

1. 把启动窗口里 **`校园网访问`** 那一行地址原样发给同学，例如
   `http://10.113.158.198:5000`
   （务必包含 `http://`，否则浏览器可能当搜索词处理）
2. 同学在同一校园网下用浏览器打开 → 出现登录页。
3. **首次使用需注册账号**：点登录页的注册入口，填写用户名与密码后即可登录。
4. 手机同样可用：连同一个 WiFi，浏览器输入同一地址。

### 三种典型拓扑（先看你在哪一类）

#### A. 同一路由器 / 同一 WiFi 下（最常见，成功率最高）

你和同学连的是同一个 AP / 同一台路由器的 LAN 口，双方在**同一网段**（例如都是 `10.113.x.x`）。

- **能否成功**：能。前提是你已放行防火墙、服务已启动。
- **判断标准**：双方 IP 前三段相同（如 `10.113.158.x`），且 `ping` 得通。
- **排查命令**：

  ```bat
  ipconfig                        :: 看自己的 IPv4 地址
  ping 10.113.158.198             :: 同学在自己电脑上 ping 你
  telnet 10.113.158.198 5000      :: 通 = 端口可达（不通则先开防火墙）
  ```

  PowerShell 更友好（Windows 10+ 默认不带 telnet 客户端）：

  ```powershell
  Test-NetConnection 10.113.158.198 -Port 5000
  ```

  看到 `TcpTestSucceeded : True` 即端口可达。

#### B. 宿舍 / 实验室不同网段，或开了 AP 隔离

现象：能 `ping` 通网关，但**同学 ping 不通你**；或压根不在同一网段（你 `10.113.x.x`，他 `192.168.x.x`）。

- **能否成功**：默认**不能**。AP 隔离（客户端隔离）会让同一 WiFi 下的设备互相不可见；跨网段则被校园网三层设备隔离。
- **判断标准**：同学 `ping <你的IP>` 全部超时，但你们各自的网关都通 → 基本可判定隔离 / 跨网段。
- **排查命令**：

  ```bat
  ping 10.113.158.198                 :: 同学执行；全超时 = 被隔离或跨网段
  tracert 10.113.158.198              :: 看在第几跳断掉
  ```

- **三条可选出路**（按推荐顺序）：
  1. **改用有线，接同一台交换机**：宿舍/实验室的有线口通常不做客户端隔离，插同一台交换机即可互访。这是最省事、最稳的办法。
  2. **请网络管理员放行**：向校园网管理员说明用途，申请同一 VLAN 或放行该端口。
  3. **内网穿透**（仅方案说明，本项目未实现）：用 `frp`（自备公网 VPS 做 frps，本机跑 frpc）或 **Cloudflare Tunnel**（`cloudflared tunnel --url http://localhost:5000`），把本机 5000 映射到一个公网可访问地址。优点是绕开内网隔离；**代价是流量出公网，安全风险显著上升，务必先设强密钥并评估合规性**。

#### C. 校园网实名认证环境下的对外暴露限制与合规

多数校园网需要**实名认证（Portal / 802.1X）**后才能上网，且通常：

- 只放行「客户端 → 外网」的访问，**禁止**校外主动连入你的电脑；
- 对私搭服务器、端口扫描、异常流量有**审计与封禁**策略；
- 宿舍区、教学区、无线区策略各不相同。

- **能否成功**：**校内互访**一般可行（同网段前提下）；**从校外访问**基本不行，且可能违规。
- **判断标准**：校内同学能打开 = 成功；校外/手机流量打不开 = 正常现象，不要试图绕过。
- **排查命令**：

  ```powershell
  Test-NetConnection <你的IP> -Port 5000     :: 校外同学执行，失败属预期
  ```

- **合规提醒**：
  - 本系统面向**教学 / 课程设计 / 可信校园网内部使用**，不要拿去做公网服务。
  - 不要使用内网穿透把服务暴露到公网，除非已获得学校网络管理部门许可。
  - 不要在服务里存放他人隐私数据；`qinghe.db` 含账号与设备凭据，注意保管。
  - 服务只应在你本人可控的时间段开启，用完即停。

## 五、常见问题排查表

| 现象 | 可能原因 | 排查命令 | 解决办法 |
| --- | --- | --- | --- |
| 启动报 `Address already in use` / `WinError 10048` | 端口被占用（上次没关干净） | `netstat -ano \| findstr :5000` | 双击 `stop_server.bat` 确认后结束该 PID；或改端口 `set PORT=5098` 后重启 |
| 本机能开，同学打不开 | 防火墙拦了入站 | `netsh advfirewall firewall show rule name="青禾智灌 5000"` | 右键以管理员运行 `firewall_allow.bat` |
| 同学 `ping` 得通但网页打不开 | 端口未放行 / 服务只绑了 127.0.0.1 | `Test-NetConnection <你的IP> -Port 5000` | 确认 `HOST=0.0.0.0`；放行防火墙 |
| 同一 WiFi 却互相 `ping` 不通 | **AP 客户端隔离** | `ping <你的IP>`（同学执行，全超时） | 见上文拓扑 B：改用有线同一交换机，或请管理员放行 |
| 你和同学不在同一网段 | **校园网跨网段隔离** | `ipconfig` 对比前三段 | 见上文拓扑 B：换到同一交换机 / 请管理员放行 |
| 杀毒软件（360 / 火绒 / Defender）弹窗拦截 | 安全软件拦了监听或入站 | 查看杀软「防护日志」 | 在杀软里把 `python.exe` 与端口 5000 加入信任 / 放行；或临时关闭防护测试 |
| 日志报 `database is locked` | SQLite 被多线程/多进程并发写 | 见下方「database is locked 专条」 | 只跑**一个**服务实例；关掉旧进程 |
| 页面能开但实时数据不刷新 | WebSocket 被中间设备阻断 | 浏览器 F12 → Network → WS | 本项目已用 `threading` + 长轮询兜底，刷新页面重试即可 |
| 页面 502 / 504 或一直转圈超时 | 反代（Caddy/nginx）没起来或后端挂了 | 先直连 `http://127.0.0.1:5000` 试 | 若直连正常则是反代配置问题；否则看后端窗口报错 |
| `socket.io` 连接失败（F12 Console 报 `websocket error` / 400） | 反代未转发 WebSocket 升级头，或中间设备拦截 | F12 → Network → 过滤 `socket.io` | 反代需保留 `Upgrade`/`Connection` 头（见第八节 Caddyfile）；`threading` 模式会自动降级到长轮询 |
| 控制台警告「未配置环境变量 FARM_SECRET_KEY」 | 没生成 `.env`，正在用内置兜底密钥（会话可被伪造） | 检查项目根目录有无 `.env` | 运行 `python tools/gen_secret.py` 后重启服务 |
| 启动打印「未检测到局域网 IP」 | 网卡未连网 / 只有回环 | `ipconfig` | 确认已连校园网并拿到 IPv4 地址 |
| 提示「未配置 FARM_SECRET_KEY」 | 没生成 `.env` | 看项目根有无 `.env` | 运行 `python tools/gen_secret.py` 或重跑 `start_server.bat` |
| IP 变了 / 之前发的地址打不开 | 校园网 DHCP 重新分配了地址 | `ipconfig` 看当前 IPv4 | 重新把启动窗口里新的 `校园网访问` 地址发给同学；如需固定地址可向管理员申请静态 IP 或绑定 DHCP 保留 |

### `database is locked` 专条

SQLite 同一时刻只允许一个写事务。本系统是「Flask 多线程 + MQTT 后台线程」共同写库，出现该错误通常是：

1. **同时开了多个服务实例**（例如 5000 与 5098 各跑一个）——先全部停掉，只留一个。
2. **旧的 python 进程没退干净**——`stop_server.bat` 结束后再 `netstat -ano | findstr :5000` 确认无残留。
3. 磁盘同步慢 / 数据库放在网络盘——把 `qinghe.db` 放本地磁盘。
4. 偶发单次报错可忽略（前端会自动重试）；持续报错请按上面 1、2 处理。

> 本项目已通过「线程内短事务 + 及时关闭连接」降低锁冲突；若访问量进一步增大，
> 建议迁移到 PostgreSQL/MySQL，本项目暂不涉及。

## 六、安全提示（务必阅读）

1. **校园网内是 HTTP 明文传输。** 同学访问 `http://10.x.x.x:5000` 时，登录密码、MQTT 账号口令
   都以明文经过网络。同一局域网内有心人可用抓包工具看到。**仅适合可信校园网内部使用**，
   不要用于任何真实敏感业务。
2. **必须使用随机密钥。** `tools/gen_secret.py` 生成的 `FARM_SECRET_KEY` 用于签名会话 / JWT。
   切勿把 `.env` 提交到 Git（`.gitignore` 已忽略），也不要把它发给别人。
3. **`FARM_DEBUG` 必须为 0。** 调试模式会开放 Werkzeug 调试器，攻击者可在你的机器上执行任意代码。
   `start_server.bat` 已强制设为 0；**不要**用 `run.bat` 对外提供服务。
4. **不要暴露到公网。** 本系统没有 HTTPS、没有防暴力破解的强限流，直接公网暴露风险很高。
   如需校外访问，请先获得学校网络管理部门许可，并按第七节配置 HTTPS 反代。
5. **用完即停。** 不需要时按 `Ctrl+C` 停止服务，减少暴露窗口。
6. **定期备份 `qinghe.db`**（见第六节），避免误删或损坏导致数据丢失。

## 八、可选进阶：Caddy 反向代理 + HTTPS 自签证书

> **前提**：waitress **不支持 HTTPS**（它只跑 HTTP/WSGI）。要让同学用 `https://` 访问，
> 必须在前面加一层反向代理来终止 TLS。以下为**配置样例，本项目未实现、未验证**。

### 1. 生成自签证书

```bat
mkdir certs
openssl req -x509 -newkey rsa:2048 -nodes -days 825 ^
  -keyout certs\qinghe.key -out certs\qinghe.crt ^
  -subj "/CN=10.113.158.198" ^
  -addext "subjectAltName=IP:10.113.158.198"
```

> 把 `10.113.158.198` 换成你实际的校园网 IP；自签证书必须把 IP 写进 `subjectAltName`，
> 否则浏览器一律报证书错误。

### 2. Caddyfile（放在 `Caddyfile`，与 `caddy.exe` 同目录）

```caddyfile
{
    # 局域网自签场景关掉自动 HTTPS 的证书申请
    auto_https off
}

https://10.113.158.198:5443 {
    tls certs/qinghe.crt certs/qinghe.key
    reverse_proxy 127.0.0.1:5000 {
        # SocketIO 需要 WebSocket 升级
        header_up Host {host}
    }
}
```

### 3. 启动

```bat
:: 终端 1：先起后端（仍是 HTTP，仅监听本机更安全）
set HOST=127.0.0.1
set PORT=5000
start_server.bat

:: 终端 2：起 Caddy
caddy run --config Caddyfile
```

同学访问 `https://10.113.158.198:5443`。
首次会提示「证书不受信任」——因为是自签证书，点「高级 → 继续访问」即可；
如需彻底消除告警，需把 `qinghe.crt` 导入到各客户端的「受信任的根证书颁发机构」。

> 若用内网穿透（Cloudflare Tunnel / frp + 域名），也可由它们自动签发受信任证书，
> 同样**必须先获得学校网络管理部门许可**。
